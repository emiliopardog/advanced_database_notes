# Session – 2026-02-26

## Topics covered
- Aggregate functions (COUNT, SUM, MIN, MAX, AVG, STDDEV, MEDIAN, VARIANCE, STATS_MODE)
- Using DISTINCT and ALL inside aggregate functions
- GROUP BY to summarize data by categories
- HAVING to filter grouped results
- ROLLUP and CUBE for generating subtotals and cross-tabulations

## What I understood
- Aggregate functions summarize multiple rows into a single value
- DISTINCT inside an aggregate only considers unique values, ALL considers every row
- GROUP BY splits rows into groups and applies the aggregate to each group separately
- WHERE filters rows before grouping, HAVING filters after grouping
- ROLLUP adds subtotals for each level of grouping and a grand total at the end
- CUBE generates subtotals for every possible combination of the grouped columns

## What is still confusing

- When to use STATS_MODE or VARIANCE vs just using AVG or STDDEV
