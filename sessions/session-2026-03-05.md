# Session – 2026-03-05

## Topics covered
- Window functions (OVER clause) for row-level aggregations without collapsing rows
- PARTITION BY to group calculations within categories
- ORDER BY inside OVER to create running totals and running averages
- Window frames: ROWS vs RANGE with PRECEDING, FOLLOWING, and UNBOUNDED
- Sliding windows for moving aggregations
- Ranking functions: ROW_NUMBER, RANK, DENSE_RANK
- Navigation functions: LAG, LEAD, FIRST_VALUE, LAST_VALUE

## What I understood
- Window functions let you aggregate without losing individual row detail unlike GROUP BY
- PARTITION BY works like GROUP BY but inside a window, calculating per group while keeping all rows
- ORDER BY inside OVER turns aggregates into running totals
- ROWS counts physical rows, RANGE counts by value so it groups ties together
- LAG and LEAD let you access previous and next row values without a self-join
- LAST_VALUE needs an explicit frame (RANGE BETWEEN CURRENT ROW AND UNBOUNDED FOLLOWING) to work as expected
- You can filter window function results by wrapping the query in a subquery or CTE since you can't use them in WHERE directly
